# Admin CMS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build a full WordPress-style CMS inside the existing Next.js 16 admin dashboard covering Site Settings, Posts, Pages, Media, and SEO fields.

**Architecture:** Server Actions for all mutations (no REST API layer except media upload). Prisma 7 + Neon PostgreSQL. Tiptap for rich text. Per-resource CRUD pages following a consistent list → form → save pattern.

**Tech Stack:** Next.js 16 App Router, Prisma 7, Auth.js v5, Tiptap, @prisma/adapter-pg, Zod, bcryptjs

---

## File Map

### New packages
- `@tiptap/react @tiptap/pm @tiptap/starter-kit @tiptap/extension-image @tiptap/extension-link @tiptap/extension-placeholder`
